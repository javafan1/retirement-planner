# Phase 6E-P3D3C4C — Spousal succession design

## 1. Executive summary

Preserve automatic modeled household economic succession. Design the tax layer around a separate, evidence-backed effective recipient for each actual receipt. An account stays under its original reference and owner, with the same balance, growth and withdrawal priority. An admitted ordinary IRA debit may name the survivor as payee without creating a second account or a rollover cash flow.

Recommend an **Arkansas Basic deterministic, RMD-safe own-IRA distribution subset** as the first application. Use a separately acknowledged planning assumption for a sole, direct spouse beneficiary with an unlimited right to withdraw whose own-IRA election is modeled as effective by the start of the first survivor year. Admit only qualifying fully pretax ordinary traditional IRA spending and tax-funding payments. Resolve mandatory distribution exposure before pricing. Preserve a typed refusal where the source or RMD evidence is inadequate. An actual election changes RMD treatment even in a year with zero household spending. The architecture therefore cannot promise that the reported native 2056 scenario will complete. This report defines a later approval gate and changes no financial behavior.

The evidence labels used below are **VERIFIED_OFFICIAL_RULE**, **APPROVED_MODELING_ASSUMPTION**, **SUPPORTED_EXISTING_BEHAVIOR**, **PROPOSED_EXTENSION**, and **UNSUPPORTED_OR_UNRESOLVED**. A proposed conservative limit can be narrower than the actual legal rule.

## 5. Reusable effective-recipient architecture

**PROPOSED_EXTENSION.** Use one immutable annual account disposition per original `AccountReference` and one optional immutable receipt association. The annual disposition can be a compact value in the existing Arkansas annual evidence construction, with a state-neutral shape and an Arkansas-specific approval factory. Keep it bound to the frozen input snapshot, year, execution policy and effective household death view. It reports original owner and account class, whether the modeled household has access, whether a particular transaction can name a different recipient, supported purpose and timing, and a reason when qualification is missing. It does not retain a live plan reference or expose a mutable policy registry.

- An active original owner uses existing account receipt semantics.
- An admitted successor disposition can name the living spouse for a permitted receipt. The receipt association contains effective recipient, year/window, rule identity and reviewed character, with the existing source, kind, purpose and amounts as the link. A reference to frozen qualifying facts avoids duplicating all demographic and legal inputs on each row.
- An unadmitted disposition supplies a typed reason including missing or contradictory election evidence, timing, source category, RMD, basis/penalty, or mode. The original account remains in the pool. An unavailable candidate is never recorded as a successfully paid zero-tax receipt.
- Joint and retained cash, qualified life proceeds and survivor pensions use their existing paths. The account-succession disposition is inapplicable to those receipts.

Separate rule-neutral evidence from state admission. A state can require stricter facts and refuse the projection while household economic access remains true. Use the validated annual disposition as the single authority for exact receipts and proof source classification. Construction and checks must succeed on immutable copies for both Medicare passes.
