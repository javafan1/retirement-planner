## 4. Statutory-cent versus published-table reconciliation

Let `N` be nonnegative Arkansas net taxable income after state deductions and exclusions, before tax credits. Denote `x+ = max(x,0)`. For the lower schedule, P is `.02(N−5600)+ + .01(N−11200)+ + .004(N−16000)+ + .003(N−26400)+`. These are marginal-rate *increments*. The high schedule is `.02×4700 + .037×(N−4700)`, or `.037N−79.90`, before the statutory bracket adjustment. In P, with `q=floor(N)`, use high from `q≥94701`, and subtract `290−10·floor((q−94701)/100)` only for `94701≤q≤97600`. This is a tax subtraction. In the lower schedule, marginal slices act on actual `N`. P extends the enacted whole-dollar ranges to cents by convention.

The ES reconstruction uses printed `base+rate×(N−excessOver)` through the row's printed inclusive upper cent, except for the 29 fixed-dollar rows from $94,701.00 through $97,600.99. It uses gross zero below $5,599 on the cent grid. The stated zero rule and first rate row leave every cent from $5,599.00 through $5,599.99 unanswered. The test rejects all 100 cents under ES, while P returns zero. It also tests the actual $80,001 row start and the $100,000 row reset. ## 9. Minimum-sufficient funding mathematical model

Freeze the annual household, filing status, law and source evidence, ordinary spending, Medicare pass, Social Security result, opening and projected-period RMDs, already executed investment/cash events, and the **actual completed** Roth transfer. Use the resulting immutable projected portfolio as the sole funding inventory.

| `A(w)` | Ordered account-backed actual gross withdrawals, account identity and recipient, current balance debit, and spendable and taxable amounts under the admitted source policy. An unexecuted portion does not enter this trace. |

The acceptance predicate is `C+K≥F+S` with valid same-trial evidence and exact native arithmetic. Preserve the existing two-cent settlement reconciliation guard for legacy callers. The Arkansas-specific path should close the exact ledger and must never rely on tolerance to accept a positive deficit, even a subcent. Avoid overstating `K` from an unqualified proxy, withholding or conversion. If all admissible points are proved insufficient, report capacity shortage with an executable witness. To prove the smallest deficit for failure details, maximize the residual using the same envelopes around the best endpoint of each affine cell and bounded exact evaluation. If the exact deficit proof is unavailable, label it as bounded or return typed unsupported if the existing outcome requires a precise value. At-cap tax minus cash may give the wrong diagnosis at a discontinuity.

Proposed query domain is whole cents from zero through floor-cent eligible capacity, plus the exact final capacity as a terminal candidate if it is subcent and larger than the last cent. Intermediate balance/source breakpoints retain their precision and are assigned to the first legal lattice point on each side. This is a **minimum on the specified executable query domain**. ## 10. Discontinuity and breakpoint handling

| Method | Assessment |
| --- | --- |
| Existing fixed-point updates | Appropriate only under the assumptions of existing accepted paths. A proven cycle, multiple roots and a final recomputation of a different request make it unsuitable for the new contract. More iterations leave the demonstrated problem. |
| Binary or bracket search on total residual | Only justified on a certified contiguous monotone region. A higher executable W can fail after a smaller one passes. A sign change across a step can occur without an equality root. |
| Discontinuity-aware endpoint candidates | Necessary at all steps, including end-of-range and credit steps. The endpoints alone miss a first interior sufficient cent. |
| Piecewise affine candidates with a proved rounding envelope | **Preferred.** Derive all tax and source cells for fixed inputs, then bound the only cents that can change the decision. Verify each such cent using the live tax and account-authority methods. |
| Certified bounded interval subdivision | Useful for additional supported behavior described by conservative upper/lower bounds. Prune a range only when its upper residual is strictly negative, accept the first point of a wholly sufficient range only after exact validation, and subdivide unresolved ranges within a deterministic budget. An incomplete proof is typed unsupported even when a later feasible example is known. |

Proposed `ArkansasFundingSegments` and `ArkansasMinimumFundingSolver` in `domain/tax/state/arkansas` operate on immutable exact affine/bounded cells and an authoritative trial callback. A cell carries an interval with endpoint inclusion, known executable source prefix, law/version, index of tax bands, and affine spendable/tax values or conservative residual bounds. Build cuts in this order.

1. From the real strategy and balances, construct cumulative prefixes, including the separate retained nonqualified balance. All balance caps remain exact. Each prefix segment has one partially drawn account and fixed preceding debits. Record eligibility changes, ownership changes, joint principal and unknown gain facts. If a required source has unsupported tax character, bound the admissible region or refuse. Do not skip it and silently reorder withdrawals.
2. Split the scalar ordinary income and each potential recipient pool where a §307 cap is reached, where age/date facts change admission, or when inclusion/qualification differs by source. For a fixed year and appropriately evidenced receipt interval, age is a fixed predicate for each source. At a modeled death, age, active owners and eligibility must be derived for that year. A representative date cannot prove all receipts were on or after a birthday.
3. For every legal senior choice, split state taxable net income at zero, the state standard deduction's effective floor, marginal-band starts, the lower/high transition, all 29 adjustment starts and the exit, indexed credit/eligibility steps when modeled, and the credit-to-zero tax crossing. With published regular tables, explicitly enumerate their row limits within each reachable taxable domain. If an ES substitute were approved, include **all** its resets and the publication gap. Within a region where the rate worksheet is valid, compare the at most four legal alternatives deterministically. Solve each alternative over certified cells or split at their intersections. Credit alternatives can select distinct sides of the high-income step for the same W.
4. Split federal calculations at provisional-income thresholds using the fixed gross Social Security source, 50%/85% caps and inner `min` transitions, zero taxable income and all projected federal bracket endpoints. Ordinary federal tax is unrounded multiplication of slices. If evidenced NIIT is admitted, split at the MAGI excess zero and the crossing with admitted net investment income, and include its HALF_UP error bound. Reject unsupported tax evidence. Future government rules and valid modeled adjustments can change the slopes. Read projected rules and prove a slope instead of hard-wiring a presumed slope cap.
5. Intersect these cuts with exact source/receipt boundaries. Map closed/open endpoints exactly to the current grid. Check neighboring legal cents at step boundaries, including the end-cap point. Duplicate exact BigDecimals may be deduplicated by numeric value within the same immutable trial context. Final-authority rounding can cause small nonmonotonic marginal steps even within an affine region.

For each certified cell let raw residual `g(w)=C+K_raw(w)−F_raw(w)−S_raw(w)=a+bw`. Derive a uniform error `e` covering every real rounding operation in that cell. With raw federal regular tax and state HALF_UP cents, `e=.005` if the proxy starts at unrounded state tax. A rounded anchor creates a difference of two state rounding errors, so use `e=.01` for that anchored distance. Add evidenced NIIT rounding separately if used. First pass may require outward-directed BigDecimal bounds or rational exact comparisons. Never round the root inward.

For `b>0`, every legal cent before the first `g≥−e` is impossible. A legal cent with `g≥e` is necessarily sufficient under the model. Evaluate, in increasing order, the finite uncertainty band and the first guaranteed cent if it is inside the cell. For `b<0`, a sufficient first cent wins. Otherwise exclude any ranges lying below the lower possibility bound and inspect only the bounded remaining uncertainty interval after the early point. For `b=0`, either prove the entire cell sufficient/impossible from the sign bounds, or invoke the bounded exact fallback for the unresolved cell. Agent code should check an upper-envelope exclusion certificate for all earlier *valid* cells. An earlier domain with material unknown facts cannot be discarded as zero or as insolvent. No feasible equality is required. Multiple roots resolve by the first verified sufficient candidate. A discontinuous transition itself may be that candidate, as in P.

## 13. Proposed HouseholdCashSettlement contract

`domain/projection/HouseholdCashSettlement.java` currently validates nonnegative inputs, attribution exactly equals total retained surplus (RMD plus guaranteed), and total cash sources versus uses within $0.02. Its seven-argument `calculate` computes post-expense guaranteed remainder, then RMD remainder, applies these to tax in that priority and adds their leftover amounts. Neither the current factory nor inventing total surplus without a third attributed source accepts the P example.

Proposed smallest shared extension: one immutable nonnegative `retainedFromTaxFundingSurplus` amount and a legacy-compatible old constructor/factory. Default legacy value is normalized zero. Add a specifically named factory, e.g. `settleExecutedTaxFunding(… actualFundingTrace, incomeTaxes)` or an Arkansas-local factory producing this validated settlement. Require exact spending coverage after guaranteed and projected-period RMD cash for the new path. Maintain the existing order of spending and tax cash sources. Compute residual after taxes funded from excess guaranteed cash, excess current RMD, then actual funding:

```
spendShortfall = max(expenses + Medicare - G - R, 0)
spendingWithdrawal == spendShortfall
guaranteedLeft = max(G - expenses - Medicare, 0)
rmdLeft = max(R - max(expenses + Medicare - G, 0), 0)
taxAfterGuarantee = max(taxes - guaranteedLeft, 0)
taxAfterRmd = max(taxAfterGuarantee - rmdLeft, 0)
require K >= taxAfterRmd
retainedGuarantee = max(guaranteedLeft - taxes, 0)
retainedRmd = max(rmdLeft - taxAfterGuarantee, 0)
retainedFunding = K - taxAfterRmd
totalRetained = retainedGuarantee + retainedRmd + retainedFunding
G + R + spendingWithdrawal + K == expenses + Medicare + taxes + totalRetained
```

Validate `retainedFunding≤K`, exact attribution sum, no unexecuted withdrawal or mixed-source double count, and consistent selected funder state. Make a positive funding residual unconstructible through the old factory. For new funding logic the trace must satisfy owner, account balance and spendability invariants before settlement. Preserve old validation behavior for default-zero historical results. Expose `ProjectionYear.getRetainedFromTaxFundingSurplus()` delegating to the one canonical settlement field, with JSON visibility reviewed. Keep the existing `getTaxFundingWithdrawal()` as the gross additional portfolio withdrawal. A separate spendable-cash field is unnecessary for the proposed admitted equality `W=K` and would be a distinct model extension.

## 18. Computational cost and termination

For `A` ordered source prefixes, `B` relevant cut families/rows and `Q≤4` senior alternatives, an implementation that pulls each row back through each prefix has a conservative `O(A·B·Q)` structural cut bound for a fixed annual pass in the bounded affine model. Let `K` be resulting cells. Sort/deduplicate in `O(K log K)`. With exact-authority trial cost `T` and `m_i` tested cents on cell `i`, computation after cuts is `O((K+Σm_i)T)`. `T` includes real allocation, source reconciliation and federal/state calculations, plus strategy sorting if repeated. Cached immutable ordering can reduce an allocation to a prefix walk. For nonzero residual slope `b_i` and currency grid `h=.01`, the number of uncertain cents per cell is bounded by `ceil(2e_i/(|b_i|h))+2`. For the tested $.01 anchored envelope and minimum .743 residual slope, at most five candidate cents per nonempty uncertainty window, plus the segment-first check. No assumption of globally increasing sufficiency is needed.

State/table/credit cells, unsupported gaps, near-flat residuals, scenario count and outer conversion solve can change cost materially. Establish an explicit versioned budget and maximum supported numeric precision through focused performance tests for realistic portfolios/world counts. For example, measure exact allocator/tax evaluations and memory against the existing bounded Monte Carlo and integrated benchmarks. Budget exhaustion, an uncataloged piecewise response, or failed consistency/witness assertion returns typed unsupported with a reproducible reason, never approximate success. For ordinary capacity shortage only return a funding failure after all admissible regions have been proved infeasible. A bracket-fill outer budget multiplies the cost of the inner proof and has its own upper-bound admission. Add neutral cancellation at analysis boundaries and keep all trial/simulation graphs run-local. The measured JUnit prototype time is a test execution diagnostic and gives no production throughput guarantee.
